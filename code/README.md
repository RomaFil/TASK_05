# Код для Raspberry Pi 5

Тут буде окремий проєкт з кодом для пристрою Motion Logger.

**Стан на 05.10.2026: код ще не написано.** Папка створена як місце під нього.

Що код має робити (план):
- читати датчики руху: MPU6050 (модуль GY-87, I2C) і ADXL345 (модуль GY-291, SPI);
- читати GPS NEO-6M по UART (NMEA-повідомлення `$GPRMC`, `$GPGGA`);
- керувати RGB-світлодіодом і читати дві кнопки через GPIO;
- писати лог у файл.

Підключення пінів Pi до модулів, кнопок і світлодіодів описано в [головному README](../README.md#підключення-пінів-pi-5).
