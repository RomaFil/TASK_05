# Код для Raspberry Pi 5 (демонстрація)

> **Це лише демонстрація. Код простий, на реальному залізі не перевірений і буде змінюватися.**
> Фінальна версія з'явиться пізніше (буфер, потоки, фільтр руху, запуск при старті системи).

Що робить `motion_logger_demo.py`: раз на секунду читає датчики й пише рядок у CSV-лог.

| Що | Як | Піни / адреса |
|---|---|---|
| MPU6050 (модуль GY-87) | I2C1, бібліотека `smbus2` | пін 3 (SDA), пін 5 (SCL), адреса `0x68` |
| ADXL345 (модуль GY-291) | SPI0, бібліотека `spidev` | піни 19, 21, 23, CE0 = пін 24 |
| GPS NEO-6M | UART, бібліотека `pyserial`, рядки `$..RMC` з перевіркою контрольної суми | піни 7 (TX), 29 (RX), порт `/dev/ttyAMA2` |
| Кнопка 1 / 2 | GPIO17 / GPIO13, `libgpiod` | пауза запису / позначка `MARK` у логу |
| Світлодіод | GPIO27 (червоний), GPIO22 (зелений), GPIO6 (синій) | червоний — нема GPS-фіксації, зелений — є, синій — запис |

Якщо датчик чи бібліотека недоступні, програма пише про це і працює далі без нього (у лозі порожні значення).

## Як запустити (не перевірено на Pi)

1. У `/boot/firmware/config.txt` увімкнути інтерфейси й перезавантажити:
   ```
   dtparam=i2c_arm=on
   dtparam=spi=on
   dtoverlay=uart2-pi5
   ```
   Назву overlay `uart2-pi5` перевір командою `ls /boot/firmware/overlays | grep uart`.
2. Встановити бібліотеки:
   ```
   sudo apt install python3-libgpiod
   pip install -r requirements.txt --break-system-packages
   ```
3. Перевірити датчики: `i2cdetect -y 1` (має бути `68`), `ls /dev/spidev0.0`, `ls /dev/ttyAMA*`.
4. Запустити:
   ```
   python3 motion_logger_demo.py
   ```
   Вихід: `Ctrl+C`. Лог: `motion_log.csv` у поточній папці (інша назва: змінна `LOG_FILE`; інший порт GPS: змінна `GPS_PORT`).

## Перевірка розбору даних (без Raspberry Pi)
```
python test_parsers.py
```
Перевіряє контрольну суму NMEA, розбір `$GPRMC` і перерахунок «сирих» байтів MPU6050 та ADXL345 у фізичні величини. Працює на будь-якому комп'ютері.

## Що не перевірено
- Робота на реальному Raspberry Pi 5 з платою (усі піни взято з таблиці підключень, див. [головний README](../README.md#підключення-пінів-pi-5)).
- Назва overlay UART і порт `/dev/ttyAMA2`.
- Чи дає натиснута кнопка 1 (`BUTTON_ACTIVE_HIGH = True` у коді): залежить від модуля KY-004.
- Номер `gpiochip`: програма шукає чип RP1 автоматично, запасний варіант `/dev/gpiochip0`.
